# Schema status

`task.schema.json` and `trajectory.schema.json` are legacy drafts retained from the initial general-purpose trajectory-generation scaffold. They are not finalized contracts for the current phase.

Phase 2 will define minimal task, run, event and evaluator-result contracts informed by the [Research Report](../docs/RESEARCH_REPORT.md), actual runtime observations, and the [Experiment Plan](../docs/EXPERIMENT_PLAN.md).

Keep product outcome, run termination, evaluator health and capture fidelity separate. Preserve native payloads and distinguish unavailable source values from collector metadata. Do not assume the legacy schemas already express these requirements.

This documentation update does not change or finalize machine-readable schemas.
