# Schema status

`task.schema.json` and `trajectory.schema.json` are legacy drafts retained from the initial general-purpose trajectory-generation scaffold.

They are not the event contract for the current Codex CLI educational lab. Their presence does not mean the event-schema milestone is complete.

The [research handoff](../docs/RESEARCH_PLAN.md) must first identify actual user-accessible events and payloads. A later milestone will design a simple schema from that evidence. Do not implement or finalize the new schema during the research handoff.
